# 抑えて起きたい主要な実験方法
**ARPES**は現代の武器の1つである。フルネームでAngle redolved photoemission spectroscopy、日本語で角度分解光電子分光という。角度を分解して何になるんだ、と言いたくなるが、これが重要である。要は、入射角度を変えながら光を当てて、光電効果により出てきた電子のエネルギーを測る装置である。入射角度を変えることは、電子の面内の運動量を変えることに対応する。つまり、電子の運動量=波数とエネルギーが同時にわかるのである。バンド図が可視化できるのである。特性上、表面敏感であるためトポロジカル物質の表面状態や2次元物質のバンド構造を調べるために使われる。ポンプ・プローブ法による時間分解ARPESやマイクロメートルスケールのデバイスを測るための位置分解ARPESやスピン分解ARPESが開発された。一方、ARPESは電子のエネルギーを測るときに飛行時間を用いている。そのため、磁場がありLorentz力があると測定が難しい。しかし、最近では磁場中での測定を可能にしたMagneto ARPESもできたようである。

ARPESの有名な研究者はたいていStanfordのZX Shen研を通っている。

# 2次元物質

2次元物質が流行っている。2次元物質とは原子層程度の厚さを持つ物質で、電子の動きがほぼ2次元平面上に固定されている。代表例はグラフェンでNobel賞をとっている。他にも、遷移金属ダイカルコゲナイド(MX2:M=Mo,W,Nbなど。X=S,Se,Teなど)と呼ばれる物質、MoS2やMoTe2、WTe2なども人気である。2次元物質が人気な理由の1つはその制御性である。バルク結晶にスコッチテープをペタペタするだけで高品質な薄膜を得ることができたり、ゲート電圧により電子密度を簡単に増減できたり、他の2次元物質と組み合わせて所望の構造をつくれたりする。

単層のグラフェンはディラックコーンをもつ。ディラックコーンとは、線形分散をもつバンド構造で、電子の速度が光速の1/300ほどになるという驚異的な性質をもつ。また、ディラックコーンの特性により、100%の確率でトンネル効果を起こすKleinトンネル効果や巨大な軌道反磁性、特異な光学応答を示す。グラフェンの研究で有名なのはHarvardのPhilip Kimである。現在の2次元物質界隈で有名な人(Andrea Young、Cory Dean、Pablo Jarillo-Herreroなど)は大体Philip Kim研究室を通っている。Harvard移籍前はColumbia Universityに研究室を構えていた。Columbiaには他にも多数の研究者が所属していた(る)。

グラフェンはほとんどの場合、hBN(hexagonal Boron Nitride)と組み合わせて使われる。hBNはグラフェンとほぼ同じ格子定数をもち、Si/SiO2基板と比べてとても平坦である。そのため、ラフネスを大きく軽減でき、グラフェン本来の物理を解明できる。また、角度を揃えたグラフェン/hBNの積層構造はモアレ格子を誘起し、実効的な格子定数が大きくなったことによりHofstadterの蝶の観察を可能にした。また、対称性を破ったことによりBerry曲率が有限となり、バレーホール効果を引き起こす。

グラフェンは単層でも興味深い性質を数々示していた。しかし、2018年にさらに大きなパラダイムシフトが起きる。MITのPablo Jarillo-Herrero Groupはわずかに角度をずらして積層した2層グラフェンが相関絶縁状態や超伝導を示すことを発見した。電子相関の強化は以下のように説明できる。2層グラフェンには上層と下層のディラックコーンがある。ねじれ角が大きめなときは、この2つのディラックコーンが層間のホッピングにより混成し、少しなだらかなバンド構造ができる。特に魔法角1.1°のときはバンドが完全に平坦になる。バンドが平坦ということは電子の運動エネルギーに比べ電子間相互作用が大きいということであり、強相関となる。あまりにも電子間相互作用が大きいと、電子は同じサイトに入ることができなくなり、絶縁体状態となる。これが2018年のYuan CaoのNatureの1本目である。次に、この絶縁体状態からドープをわずかに変えるだけで超伝導となることが発見された。さらに、この超伝導は電子密度に対して臨界温度が大きく、いわゆる高温超伝導と言われる物質たちと同程度であった。また、相図上で相関絶縁体状態と超伝導が隣接していことは銅酸化物超伝導と類似している。このことからMagic angle twisted bilayer graphene(MATBG)はunconventional superconductorだと考えられた。炭素原子のみからなるグラフェンがひねって積層するだけで強相関電子系の物理を発現するした。このことはその後大きなブームを引き起こした。
