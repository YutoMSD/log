#物性物理で最近流行っているもの

**2026/07/02**

2次元物質が流行っている。2次元物質とは原子層程度の厚さを持つ物質で、電子の動きがほぼ2次元平面上に固定されている。代表例はグラフェンでNobel賞をとっている。他にも、遷移金属ダイカルコゲナイド(MX2:M=Mo,W,Nbなど。X=S,Se,Teなど)と呼ばれる物質、MoS2やMoTe2、WTe2なども人気である。2次元物質が人気な理由の1つはその制御性である。バルク結晶にスコッチテープをペタペタするだけで高品質な薄膜を得ることができたり、ゲート電圧により電子密度を簡単に増減できたり、他の2次元物質と組み合わせて所望の構造をつくれたりする。

単層のグラフェンはディラックコーンをもつ。ディラックコーンとは、線形分散をもつバンド構造で、電子の速度が光速の1/300ほどになるという驚異的な性質をもつ。また、ディラックコーンの特性により、100%の確率でトンネル効果を起こすKleinトンネル効果や巨大な軌道反磁性、特異な光学応答を示す。グラフェンの研究で有名なのはHarvardのPhilip Kimである。現在の2次元物質界隈で有名な人(Andrea Young、Cory Dear、Pablo Jarillo-Herreroなど)は大体Philip Kim研究室を通っている。Harvard移籍前はColumbia Universityに研究室を構えていた。Columbiaには他にも多数の研究者が所属していた(る)。

グラフェンはほとんどの場合、hBN(hexagonal Boron Nitride)と組み合わせて使われる。hBNはグラフェンとほぼ同じ格子定数をもち、Si/SiO2基板と比べてとても平坦である。そのため、ラフネスを大きく軽減でき、グラフェン本来の物理を解明できる。また、角度を揃えたグラフェン/hBNの積層構造はモアレ格子を誘起し、実効的な格子定数が大きくなったことによりHofstadterの蝶の観察を可能にした。また、対称性を破ったことによりBerry曲率が有限となり、バレーホール効果を引き起こす。

グラフェンは単層でも興味深い性質を数々示していた。しかし、2018年にさらに大きなパラダイムシフトが起きる。
