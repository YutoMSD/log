備考

**吉田育英会** 書類は標準的。面接は8分プレゼン、22分質疑応答。面接官は5,6人で各分野の専門家が一人ずついた。物性の専門家はいなかったのでうまく伝わらなかった。ゆるい雰囲気。研究のインパクトを誰にでも理解できるように伝えるのが重要。プレゼン自体はそんなに興味ないかも。

**伊藤国際** 手書きが1枚ある。志望校は1校しか書けなかったが、変更は可能らしい。

**船井財団** 書類はテンプレを気にせず自由に使ってよい。面接は1対10以上。書類をもとにランダムに質問してくる。受かったあとのサポート(交流会やSoP・推薦書の添削など)が手厚い。志望校の変更が自由。

**JASSO** 書類が超大変。面接はオンライン。専門家っぽい人が一人いて、ちゃんと実現可能性や意義を詰められた。
