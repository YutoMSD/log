# SoP (Statement of Purpose)

志望動機書のようなもの。11 ptでUS letter2.5枚くらいが限度だろう。1枚しばりや、1000 wordsしばりもあったりする。推薦書とは異なり、主観的な文章にする。感情や情熱や夢を語ってよい。パッションを見せつつも自分の有能さを示す。

特に加藤雄一郎さんのこちらの[記事](https://katogroup.riken.jp/pdfs/SoP-advice.pdf)がわかりやすい。また、XPLANEの[SoP執筆支援プログラム](https://xplane.jp/tag/sop-writing-support/)にはお世話になった。

物理系の場合は以下のような構成になる。

**1st** 大まかな経験、大学院でやりたいこと志望動機を端的に述べる。

**2nd** アピールポイント。論文や奨学金など。最後の方でもよい。

**3rd~5th** これまでの研究内容。分量は柔軟に。

**6th** 興味のある研究室3つほど。

**7th** まとめ

推薦書より重要度は落ちるが、その次くらいには大事ある。特に、**6th**の自分の興味は意外と読まれている。何と誰をメンションすべきかは結構大事。メンションした人が面接官になることもある。
